# Internee.pk Website Redesign

## WordPress Website Development Project

A redesigned version of the **Internee.pk website** developed using WordPress in a local XAMPP environment. The project focuses on creating a clean, organized, user-friendly and responsive website while implementing basic SEO, security, performance and content-management features.

---

## Project Information

* **Project Name:** Internee.pk Website Redesign
* **Submitted By:** Sadia Shabir
* **Platform:** WordPress
* **Development Environment:** XAMPP / Localhost
* **Database:** MySQL
* **Page Builder:** Elementor
* **Project Type:** Website Redesign and Optimization

---

## Project Objectives

The main objectives of this project were:

* Set up a WordPress website in a local environment.
* Redesign and customize the website layout.
* Organize content into appropriate pages and sections.
* Create a user-friendly navigation structure.
* Configure essential WordPress plugins.
* Implement basic on-page SEO.
* Configure SEO-friendly URLs.
* Improve website security and performance.
* Create documentation for future website maintenance.
